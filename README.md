# La2 Trader Timer

Приложение для Windows x64, которое помогает следить за временем пересадки персонажей-трейдеров в Lineage II.

## Скачать и начать

Откройте страницу [последнего релиза](https://github.com/AbobaCDA/La2TraderTimer-LTT-/releases/latest) и скачайте установщик `Forge-Crafter-Manager-Setup-...exe` из раздела **Assets**. Запустите установщик, добавьте персонажа и нажмите **«Начать смену»** в момент посадки трейдера.

Длительность смены — **12 часов без торговой лицензии** и **24 часа с лицензией**. В каждой карточке можно указать или изменить фактические дату и время посадки. Кнопка **«Склад персонажей»** скрывает ненужного персонажа и останавливает его таймер; вернуть его можно одним нажатием. Автозапуск Windows настраивается переключателем в приложении.

## Обновления и данные

Приложение проверяет обновления при запуске. Когда новая версия будет скачана, нажмите **«Перезапустить»**. Старые версии без автообновления нужно один раз обновить вручную установщиком из релиза; после этого новые версии будут устанавливаться через приложение.

Без входа в аккаунт список персонажей и таймеры хранятся на компьютере: `%APPDATA%\ForgeCrafterManager\characters.json`. При входе в аккаунт список и склад синхронизируются между устройствами; в Telegram склад открывается командой `/warehouse`.

## Безопасность

Приложение не подписано сертификатом Authenticode, поэтому Windows может показать предупреждение SmartScreen. Проверка Authenticode-подписи обновлений отключена. Скачивайте установщик только со страницы релизов этого проекта.
